# Luma Sprachstudio

A fictional conversation-led language studio, built as a public portfolio demo. Not an actual school or client endorsement.

## Run locally

Use the globally installed Portless: `portless` from this directory, then `portless get luma-sprachstudio`. The server honours assigned PORT and HOST. No package installation or build is required.

## Verify and deploy

`npm run check` verifies JavaScript syntax. Vercel serves the `dist` directory.

DE/EN interface, responsive navigation and reduced-motion support are included. Enquiry forms produce a local preview only: no email or form request is sent. Only the language preference is stored locally.

Brand, staff and offers are fictional. AI-generated images live in `dist/assets`; generation notes are in ASSETS.md.
